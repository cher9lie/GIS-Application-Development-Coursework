# 作业 6：地图符号化

程序可打开 MXD，并按图层几何类型设置单一符号；还实现唯一值、柱状图、饼图和五级分级符号渲染。

几个专题渲染按钮针对课程示例数据编写，字段名是源码中的固定约定：

- 唯一值渲染：`CONTINENT`
- 柱状图、饼图：`SQMI`、`SQKM`
- 分级符号：`SQKM`

因此应加载含这些字段的面图层；换用其他数据时，需要先在 `Form1.cs` 中替换字段名和分级范围。原说明把这些功能描述成通用自动适配，实际只有“单一符号”会根据点、线、面自动选择符号类型，这里已据源码更正。

打开 `MapSymbolizationLab.sln`，使用 ArcGIS Engine 10.2、.NET Framework 4.0、x86 编译。
