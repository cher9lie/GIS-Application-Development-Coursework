# 作业 8：属性查询、空间查询与缓冲区

## 作业目标

本作业练习三种常见 GIS 操作：由属性定位地图要素、由地图范围获取属性，以及调用 ArcGIS Geoprocessor 生成缓冲区。

## 环境与入口

- Visual Studio 2010
- .NET Framework 4.0
- ArcGIS Engine 10.2
- 目标平台：x86
- 解决方案：`GISDev8.sln`
- 主要代码：`GISDev8/Form1.cs`
- 查询结果窗口：`GISDev8/frmAttribute.cs`

## 界面功能

- “加载数据”：加载 Shapefile 并缩放至全图
- “属性查图”：按村名查询并定位
- “图查属性”：在地图上框选并显示结果表
- “缓冲区分析”：调用 GP Buffer 工具生成 500 米缓冲区
- ArcGIS 工具条：与 MapControl 绑定，可辅助浏览地图

## 属性查图

操作流程：

1. 点击“加载数据”，选择 Shapefile。
2. 确认它是地图中的第一个图层。
3. 在“村名”输入框填写完整名称。
4. 点击“属性查图”。
5. 程序按 `NAME = '输入值'` 精确查询。
6. 找到结果后高亮第一个命中要素，并把地图范围调整到该要素附近。

查询不是模糊匹配。字段值、空格和文字必须与属性表一致。输入中的单引号已进行转义，避免查询表达式被破坏。

## 图查属性

1. 点击“图查属性”。
2. 在地图上拖出矩形。
3. 程序用 `Intersects` 空间关系搜索第一个图层。
4. 命中要素在地图上高亮。
5. 新窗口显示每个结果的 OID 和 `NAME` 值。

如果数据没有 `NAME` 字段，结果表中的 Name 列会为空，但 OID 仍可显示。

## 缓冲区分析

1. 先加载 Shapefile。
2. 点击“缓冲区分析”。
3. 在保存对话框中指定输出 `.shp`。
4. 程序对第一个图层的完整 Shapefile 执行 `Buffer`。
5. 距离固定为 `500 Meters`。
6. 分析成功后，结果 Shapefile 自动加载回地图。

需要注意：缓冲区输入是整个第一个图层，不是当前选中的要素。输出同名文件允许覆盖。

## 数据要求

- 只加载 Shapefile。
- 属性查询要求字段名为大写 `NAME`。
- 缓冲区工具根据第一个图层的数据集路径构造输入，因此它也应是磁盘上的 Shapefile。
- 500 米缓冲应使用以米为单位或能正确进行距离转换的投影坐标系。
- 如果输入是经纬度坐标或空间参考缺失，应先在 ArcMap 中定义/投影坐标系。

## 本次整理修复

- 没有图层时给出明确提示
- 查询前验证 `NAME` 字段
- 转义字符串查询中的单引号
- 空间查询前清除旧选择并释放 COM 游标
- 缓冲区输出由用户选择，不再写死固定临时目录
- 分析完成后从实际保存位置加载结果

## 已知限制

- 所有操作默认针对索引 0 的第一个图层。
- 属性查询只定位第一个命中要素。
- 查询结果表只展示 OID 和 NAME，没有动态展示全部字段。
- 缓冲距离没有界面输入项，固定为 500 米。
- GP 失败时界面只显示异常摘要，没有展开全部地理处理消息。
