# 科学计算器 (Scientific Calculator)

一个功能完整的科学计算器，使用C#和Windows Forms开发，兼容Visual Studio 2010。

## 功能特性

### 基本运算
- 加法 (+)、减法 (-)、乘法 (×)、除法 (÷)
- 小数点运算支持
- 正负号切换
- 百分比计算

### 科学函数
- 平方根 (√)
- 三角函数：sin、cos、tan（角度制）
- 对数函数：log（常用对数）、ln（自然对数）
- 指数函数：exp、x^y（幂运算）
- 倒数计算 (1/x)

### 数学常数
- π (圆周率)
- e (自然对数底数)

### 内存功能
- MC (Memory Clear) - 清除内存
- MR (Memory Recall) - 读取内存
- M+ (Memory Add) - 内存加法
- M- (Memory Subtract) - 内存减法

### 清除功能
- C (Clear) - 完全清除
- CE (Clear Entry) - 清除当前输入
- 退格键 (←) - 删除最后一位数字

### 键盘支持
- 数字键 0-9
- 运算符 +、-、*、/
- 小数点 (.)
- 回车键 (Enter) - 等号功能
- Esc键 - 完全清除
- 退格键 (Backspace) - 删除最后一位
- Delete键 - 清除当前输入

## 系统要求

- Windows XP/Vista/7/8/10/11
- .NET Framework 4.0 或更高版本
- Visual Studio 2010 或更高版本（用于开发）

## 鲁棒性设计

### 错误处理
- **除零保护**: 防止除数为零的运算
- **数值溢出**: 处理超出数值范围的计算结果
- **无效运算**: 处理未定义的数学运算（如负数开方、零的负数次幂等）
- **输入验证**: 限制输入长度，防止过长数字输入
- **异常捕获**: 全方位的异常处理机制

### 用户体验优化
- **输入限制**: 最大15位数字显示，防止界面溢出
- **科学记数法**: 自动处理极大或极小数值的显示
- **内存指示器**: 显示内存中是否有值
- **键盘快捷键**: 支持完整的键盘操作
- **友好错误信息**: 中文错误提示，便于用户理解

### 常见错误处理
1. **"除数不能为零"** - 尝试除以零时
2. **"负数无法开平方根"** - 对负数开方时
3. **"对数函数的输入必须大于零"** - 对非正数求对数时
4. **"不能计算零的倒数"** - 计算零的倒数时
5. **"数值溢出"** - 计算结果超出范围时
6. **"未定义的数学运算"** - 其他数学错误时

## 使用说明

### 基本计算
1. 点击数字按钮输入数字
2. 点击运算符按钮选择运算
3. 输入第二个数字
4. 点击等号"="查看结果

### 科学函数
1. 输入数值
2. 点击相应的科学函数按钮
3. 结果立即显示

### 内存操作
1. **存储值**: 输入数值后点击"M+"将值加到内存
2. **读取值**: 点击"MR"将内存中的值显示到屏幕
3. **清除内存**: 点击"MC"清空内存

## 技术特点

- **双精度浮点运算**: 确保计算精度
- **角度制三角函数**: 三角函数使用角度而非弧度
- **内存持久化**: 内存值在计算过程中保持
- **状态管理**: 完善的计算状态跟踪
- **防误操作**: 智能的操作序列处理
