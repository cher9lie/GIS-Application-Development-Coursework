# 作业 1：科学计算器

## 作业目标

本作业是课程中的 WinForms 基础练习，用于熟悉控件事件、运算状态管理、异常处理和键盘输入。它不依赖 ArcGIS，可单独在 Visual Studio 2010 中运行。

## 环境与入口

- Visual Studio 2010
- .NET Framework 4.0
- 目标平台：x86
- 解决方案：`ScientificCalculator.sln`
- 主窗体代码：`ScientificCalculator/CalculatorForm.cs`

## 功能说明

基础运算包括：

- 加、减、乘、除
- 幂运算 `x^y`
- 小数和正负号
- 等号、退格、清除当前输入、全部清除
- 连续运算与重复开始新一轮计算

科学函数包括：

- 平方、平方根
- `sin`、`cos`、`tan`
- 常用对数 `log`、自然对数 `ln`
- 指数函数 `exp`
- 倒数 `1/x`
- 百分比
- 常数 π 和 e
- 阶乘

内存功能包括 `MC`、`MR`、`M+`、`M-`。有内存值时界面会显示内存状态标记。

## 操作方法

1. 打开解决方案并选择 x86。
2. 生成并运行。
3. 用数字按钮输入操作数，再选择运算符和第二个操作数。
4. 点击等号得到结果。
5. 科学函数直接作用于当前显示值。
6. 三角函数输入单位为“度”，程序内部会转换为弧度。
7. 键盘可使用数字、小数点、数字键盘四则运算符、Enter、Backspace、Delete 和 Escape。

百分比的处理与普通计算器一致：在加减运算中，第二个操作数的百分比按第一个操作数计算；其他情况下按当前数除以 100。

## 输入限制与错误处理

- 最多接受 15 位有效数字输入。
- 阶乘只接受 0–170 的整数，避免无意义输入和双精度溢出。
- 负数不能开平方。
- `log` 和 `ln` 的输入必须大于 0。
- 除数和倒数的分母不能为 0。
- `tan` 在余弦接近 0 的位置会提示无定义。
- 结果过长时以适当格式显示；异常不会让程序直接崩溃。

## 本次整理修复

原始源码已在基线提交中保留。本次在其后修复了：

- 长结果显示后无法开始输入新数字
- 窗体与显示框同时处理键盘事件造成的重复输入
- 正切无定义点用浮点数精确等于 0 判断不可靠
- 加减场景中的百分比语义不符合常见计算器
- 一元函数执行后意外清除待完成的二元运算

## 学习重点

建议阅读 `CalculatorForm.cs` 中的几个状态变量：当前值、上一操作数、当前运算符、新数字标记和等号标记。这个作业的核心并不是公式本身，而是如何让按钮序列形成一致的计算状态机。

## 已知边界

这是教学用双精度计算器，不提供任意精度、表达式解析、括号或历史记录。极大数和极小数会受到 `double` 精度限制。
