# 作业 1：科学计算器

这是本课程的第一个作业，不依赖 ArcGIS。工程为 Visual Studio 2010 WinForms 项目，目标为 .NET Framework 4.0、x86。

## 功能

支持四则运算、小数、正负号、连续运算、退格和清空；科学函数包括平方、平方根、倒数、三角函数、自然对数、常用对数、指数、阶乘、圆周率和百分比。键盘数字、运算符、Enter、Backspace、Escape 也可操作。

本次核对修复了长结果后无法继续输入、键盘事件重复触发、正切接近无定义点、百分比语义以及一元函数会意外清除待执行二元运算等问题。

## 运行

打开 `ScientificCalculator.sln`，选择 x86 后编译运行。阶乘只接受 0–170 的整数；除零、无效函数定义域和数值溢出会显示错误提示。
