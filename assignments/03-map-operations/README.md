# 作业 3：地图基本操作与要素识别

## 作业目标

本作业在作业 2 的控件框架上增加代码控制的地图操作，练习 MapControl 的范围变化、鼠标交互和基于空间过滤器的要素识别。

## 环境与入口

- Visual Studio 2010
- .NET Framework 4.0
- ArcGIS Engine 10.2
- 目标平台：x86
- 解决方案：`GISDev/GISDev.sln`
- 主要代码：`GISDev/GISDev/Form1.cs`

## 已实现功能

- 打开 ArcMap 地图文档（MXD）
- 全图显示
- 拉框放大
- 拉框缩小
- 鼠标拖动漫游
- 点击识别可见要素图层
- 显示命中要素的图层名、OID 和非几何属性

## 操作步骤

1. 启动程序，点击打开地图按钮。
2. 选择一个 ArcGIS 10.2 能读取、且数据源有效的 `.mxd`。
3. 点击“全图”查看所有图层范围。
4. 选择“放大”或“缩小”后，在地图上拖出矩形。
5. 选择“漫游”后，在地图上按住鼠标拖动。
6. 选择识别工具，再点击地图上的要素。
7. 程序会遍历全部可见要素图层，用点击点附近约 4 个屏幕像素的包络矩形执行 `Intersects` 查询，并在消息框中列出结果。

识别并不是调用默认 Identify 窗口，而是直接创建 `ISpatialFilter` 并搜索每个可见 `IFeatureLayer`。因此这个作业适合学习屏幕容差、空间关系和 COM 游标释放。

## 数据要求

- 必须先加载有效 MXD。
- MXD 中至少应有一个可见的要素图层。
- 如果 MXD 中出现红色感叹号，需要先在 ArcMap 中修复数据源。
- 栅格图层不会被识别逻辑处理。
- 多个图层在点击位置都有要素时，结果会合并显示。

## 代码结构

`m_BasicOperationTool` 保存当前工具状态。工具栏按钮只切换状态和鼠标样式，真正的放大、缩小、漫游和识别发生在 `axMapControl1_OnMouseDown` 中。

## 事件分派和点击识别

工具条按钮切换当前操作，主地图的 `OnMouseDown` 再按当前模式执行相应动作。缩放和漫游改变视图范围，识别模式则将点击位置转换为地图坐标，构造带容差的矩形。容差按当前地图宽度与控件像素宽度折算，缩放后仍大致维持相同的屏幕命中范围。

识别按可见要素图层遍历，用 `ISpatialFilter` 施加相交条件，再从 `IFeatureCursor` 读取要素及其非几何字段。可用重叠的两个可见图层做对照实验，验证一次点击可命中多个图层。若把本示例扩展到不同工作空间，建议显式使用目标类的 `ShapeFieldName` 设置 `GeometryField`，并确认点击几何与目标数据的空间参考一致。[Esri 空间查询示例](https://resources.arcgis.com/en/help/arcobjects-net/componentHelp/0049/004900000087000000.htm)

## 已知限制

缩小操作以当前视图范围为基础，按当前范围与拉框范围的比例扩大显示范围。拉很小的框也会缩小地图。取消文件选择或拉框为空时保留原视图。

- 打开文件对话框取消后仍会检查空路径，并可能提示“不是有效地图文档”。
- 查询结果使用消息框显示，大量命中要素时可读性有限。
- 工具状态是字符串，适合教学演示，不适合大型工程。
- 工程中保留了一些“调试”提示文字，这是原实验代码的一部分。

## 常见问题

点击识别没有结果时，依次检查：是否已经选择识别工具、图层是否可见、点击位置是否真正落在要素附近，以及图层是否为可查询的矢量图层。
