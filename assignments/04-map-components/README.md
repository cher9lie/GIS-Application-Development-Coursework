# 作业 4：地图组件、鹰眼与属性操作

## 作业目标

本作业把图层管理、地图浏览、鹰眼联动、属性查询、空间选择和属性表放在同一窗体中，练习 MapControl、TOCControl 以及要素选择接口之间的协作。

## 环境与入口

- Visual Studio 2010
- .NET Framework 4.0
- ArcGIS Engine 10.2
- 目标平台：x86
- 解决方案：`GISDev4.sln`
- 主窗体：`GISDev4/Form1.cs`
- 属性表窗体：`GISDev4/Form2.cs`

程序按 Advanced、Standard、Basic、Engine 的顺序尝试获取可用许可。

## 已实现功能

- 加载 Shapefile
- 删除地图中的第一个图层
- 全图显示、拉框放大、拉框缩小、漫游
- 主地图与鹰眼地图同步
- 在鹰眼中绘制当前主视图范围
- 在鹰眼中点击或拖动以调整主地图范围
- 按 `NAME` 字段精确查询
- 拉框选择要素
- 在 TOC 图层上右键打开属性表

原报告曾称“加载”支持 TIF、IMG 等栅格，但源码使用的是 Shapefile Workspace，因此当前实现只支持 SHP。README 已按源码更正。

## 操作步骤

1. 启动程序，点击“加载”，选择一个 `.shp`。
2. 使用“全图”“放大”“缩小”“漫游”浏览数据。
3. 在“区县”文本框输入完整名称，点击“查询”。
4. 查询会针对地图中的第一个要素图层，用 `NAME = '输入值'` 精确匹配并高亮。
5. 点击“选择”，在主地图上拖出矩形，选择相交要素。
6. 在左侧 TOC 的图层名称处单击右键，选择“打开属性表”。
7. 在鹰眼图中点击或拖动红色范围框，可帮助快速定位主地图。

## 数据与字段要求

- 加载时只接受 Shapefile。
- Shapefile 应整套保留 `.shp`、`.shx`、`.dbf`，最好还有 `.prj`。
- 属性查询要求第一个图层存在名为 `NAME` 的字段，且当前实现为精确匹配。
- 若字段名为 `Name`、中文名或其他名称，需要修改 `Form1.cs` 中的字段名。
- 删除按钮删除的是索引 0 的图层，不是任意当前选择图层。

## 鹰眼原理

主地图范围变化时，程序把主地图图层复制到第二个 MapControl，并用图形元素表示当前视图范围。鹰眼只用于导航，不是独立的数据编辑窗口。

## 本次整理修复

- 查询前检查 `NAME` 字段是否存在
- 对查询文本中的单引号进行转义
- 把“打开属性表”从菜单打开事件改到菜单项点击事件，避免右键菜单一弹出就直接打开窗口

## 已知限制

- 属性查询和删除功能都默认操作第一个图层。
- 属性表一次性读取要素属性，大数据量时可能较慢。
- 鹰眼图层同步逻辑适合少量普通要素图层，不处理复杂组图层和高级渲染。
