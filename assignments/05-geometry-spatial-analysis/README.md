# 作业 5：几何处理与前方交会

## 作业目标

本作业围绕 ArcObjects 几何接口展开，包含折线加密、点沿线动态移动和由两个观测方向求交点三个部分。界面将实验情境包装为“扑火跟踪”和“火点定位”。

## 环境与入口

- Visual Studio 2010
- .NET Framework 4.0
- ArcGIS Engine / ArcObjects 10.2
- 目标平台：x86
- 解决方案：`GISDev5.sln`
- 主要代码：`GISDev5/Form1.cs`
- 示例数据：`GISDev5/Data`

程序会依次尝试 Advanced、Standard、Basic 和 Engine 许可。

## 附带数据

`Data` 目录包括：

- `FireResponse.mxd`
- `FireLine.shp` 及其配套文件
- 瞭望塔 Shapefile 及其配套文件

项目文件把 `Data/*.*` 设置为内容，编译时会复制到输出目录。因此程序优先查找 `Application.StartupPath\Data\FireResponse.mxd`，不再依赖某台电脑上的固定盘符。

MXD 仍可能保留原数据源路径。如果图层引用失效，程序会尝试直接加载输出目录中的 `FireLine.shp`。

## 功能一：扑火跟踪

程序从地图中查找线图层，取得第一条折线并执行：

1. 用 `IPolycurve.Densify` 对折线加密。
2. 最大分段长度取整条线长度的约 1/100。
3. 将加密后的点序列保存为 `IPointCollection`。
4. 点击“扑火跟踪”后启动计时器。
5. 计时器每 50 毫秒取下一个点，更新地图上的车辆/标记位置。
6. 到达末端后停止。

这部分展示了“几何离散点 + Timer + Graphic Element”的动态显示方式，并不是真实车辆定位或网络路径规划。

## 功能二：火点定位

程序把加密折线的首点和尾点当作两座瞭望台。用户分别输入两个观测角度后，程序：

1. 将角度从度转换为弧度。
2. 调用 `IConstructPoint.ConstructAngleIntersection`。
3. 求两条观测方向线的交点。
4. 在地图上绘制火点标记。
5. 显示计算所得 X、Y 坐标。

这里输入的是两个方向角，不需要输入距离。原说明中若出现“距离与方位角同时输入”的表述，与当前源码不符。

## 操作步骤

1. 生成并启动程序。
2. 程序自动尝试加载随项目附带的 MXD。
3. 若自动加载失败，在文件对话框中选择一个包含线图层的 MXD。
4. 确认地图中存在至少一条线要素。
5. 点击“扑火跟踪”观察标记沿线移动。
6. 在两个角度输入框中填写数值，例如根据实验数据选取不会近似平行的两个方向角。
7. 点击“火点定位”，查看交点和坐标。

## 数据与数值注意事项

- 角度单位是度。
- 坐标单位由地图空间参考决定。
- 两条观测线平行或近似平行时，交会结果可能失败或数值不稳定。
- 程序使用找到的第一条线要素，数据中有多条线时不会让用户选择。
- 示例线非常简单，主要用于验证算法和界面流程。
