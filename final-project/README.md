# 综合实习：福田 GIS 系统

## 项目说明

这是课程综合实习项目，使用 ArcGIS Engine 10.2、ArcObjects 和 WinForms 实现一个桌面 GIS 原型。它把前面作业中的地图加载、渲染、识别、查询、选择、统计、缓冲区、编辑和地图输出组合在同一应用中，并增加 Network Analyst 路径分析。

项目定位是教学演示，不是生产级 GIS 平台。README 按当前源码描述功能和限制，不沿用原报告中无法由源码验证的表述。

## 环境与入口

- Visual Studio 2010
- .NET Framework 4.0
- ArcGIS Engine 10.2 Runtime 与 Developer Kit
- 目标平台：x86
- 普通功能：ArcGIS Engine 许可
- 路径分析：Network Analyst 扩展许可
- 解决方案：`FuTianGIS/FuTianGIS.sln`
- 主程序：`FuTianGIS/FuTianGIS/Form1.cs`
- 登录窗口：`FuTianGIS/FuTianGIS/LoginForm.cs`
- 默认地图：`FuTianGIS/FuTianGIS/Resources/Futian.mxd`

## 启动与默认地图

主窗体加载时会从程序输出目录下的 `Resources/Futian.mxd` 自动加载默认地图。项目文件应把该 MXD 复制到输出目录。

需要区分“MXD 文件存在”和“MXD 数据完整”：

- 仓库保存了 `Futian.mxd`
- MXD 本身主要保存地图配置和数据源引用
- 若底层 Shapefile、GDB 或网络数据集不在原路径，图层仍可能出现红色感叹号
- 此时可在 ArcMap 中修复数据源并重新保存 MXD，或在程序中使用“加载图层并渲染”

## 主界面功能

### 1. 加载图层并渲染

程序支持三类矢量数据源：

- Shapefile（`.shp`）
- Personal Geodatabase（`.mdb`）
- File Geodatabase（`.gdb` 文件夹）

操作时会先询问是否加载 File GDB：

- 选择“是”：用文件夹选择器选择以 `.gdb` 结尾的目录
- 选择“否”：用文件选择器选择 SHP 或 MDB
- 选择“取消”：终止加载

加载后，程序从可用字段中选择字符串或整数类字段，并尝试按字段执行唯一值渲染。SHP 直接打开对应要素类；MDB/GDB 当前实现选取其根目录中的要素类，不遍历要素数据集。

### 2. 图层选择

TOCControl 用于显示地图图层。许多功能会优先使用 TOC 中当前选择的要素图层；未正确选择图层时，程序可能回退到可用图层或给出提示。

在执行搜索、拉框选择、统计、属性编辑、新增点和缓冲区前，先在 TOC 中点击目标图层，可减少操作歧义。

### 3. 点击识别

在普通地图点击模式下，程序在鼠标位置附近查找可见要素，并显示其图层和属性。若点击处没有要素，会给出提示。

识别依赖要素图层和有效数据源，不处理断开的图层。

### 4. 属性搜索

搜索框针对当前要素图层的 `DisplayField`：

- 字符串字段：使用 `LIKE '%关键字%'` 模糊匹配
- 数值字段：要求输入有效数字并做精确匹配

命中要素会被选中，程序合并其几何范围并缩放到选择结果附近。若图层的 DisplayField 无效，需要在 ArcMap 或代码中设置合适的显示字段。

### 5. 拉框选择

1. 在 TOC 中选择目标要素图层。
2. 点击“拉框选择”。
3. 在地图上拖出矩形。
4. 程序用空间相交关系选择要素。
5. 选择结果会高亮，并用于后续统计、缓冲区和属性编辑。

### 6. 属性统计

程序从目标图层中查找适合统计的字段，并用单独的统计窗体展示结果。统计窗体包含图表和字段信息，用于观察当前选择或图层属性。

统计结果取决于字段类型和选择集。几何字段、OID 等不适合直接统计的字段会被排除。

### 7. 生成缓冲区

“缓冲区”以当前选中要素为输入：

1. 先通过搜索或拉框选择一个或多个要素。
2. 点击“缓冲区”。
3. 程序合并有效几何。
4. 对合并结果执行 `Buffer(500.0)`。
5. 把缓冲区作为地图图形绘制并缓存，供“周边查询”使用。

这里的 500 是地图坐标单位，不会自动保证是米。若数据使用以米为单位的投影坐标系，可解释为约 500 米；若是经纬度坐标，结果会不合理。

### 8. 周边查询

“周边查询”使用最近一次生成的缓冲几何，对目标要素图层执行空间选择。必须先成功生成缓冲区，否则程序会提示先执行“缓冲区”。

缓冲区图形是临时显示和内存状态，不会自动保存为 Shapefile。

### 9. 属性编辑

1. 先选择要编辑的要素。
2. 点击“属性编辑”。
3. 从可编辑字段中选择字段。
4. 输入新值。
5. 程序根据字段类型转换输入，在编辑事务中更新所选要素并保存。

几何字段和 OID 不提供编辑。数据源必须可写且支持 `IWorkspaceEdit`。该操作会直接修改原数据，练习前应复制数据。

### 10. 新增点

1. 在 TOC 中选择一个点要素图层。
2. 点击“新增点”。
3. 在地图上单击新点位置。
4. 程序创建点要素，并按可编辑字段提示输入属性。
5. 成功后提交编辑事务并刷新地图。

如果当前图层不是点图层、数据只读或工作空间不支持编辑，程序会拒绝操作。

### 11. 路径分析

路径分析不是对任意道路图层直接运行。它要求当前地图中已经存在由 ArcMap/Network Analyst 配置并保存的路径分析图层，且上下文中包含：

- `Stops`
- `Routes`
- 有效的 Network Dataset
- 可用的 Network Analyst 扩展许可

推荐流程：

1. 在 ArcMap 中基于道路网络数据集建立 Route 图层。
2. 确认路线图层能够在 ArcMap 中正常求解。
3. 把它保存到 `Futian.mxd`。
4. 启动程序并确认 MXD 数据源未断开。
5. 点击“路径分析”。
6. 按提示在地图上依次点击起点和终点。
7. 程序向 Stops 写入两个位置，调用求解器，再把路线几何绘制到地图。

当前源码保留了部分调试消息，例如 Stops 数量提示。这有助于课堂排查，但不属于完善的最终用户体验。

### 12. 导出 PDF

点击“导出PDF”后选择保存位置，程序通过 `ExportPDFClass` 导出当前地图视图。输出的是地图视图，不是完整的独立报表系统。

## 推荐演示顺序

为了减少前后状态不一致，建议按下面顺序演示：

1. 登录。
2. 检查默认 MXD 是否正常。
3. 加载一个可用的 SHP/GDB/MDB 图层。
4. 在 TOC 中选择目标图层。
5. 测试搜索和点击识别。
6. 拉框选择若干要素。
7. 查看属性统计。
8. 对选择结果生成缓冲区。
9. 执行周边查询。
10. 用数据副本测试属性编辑或新增点。
11. 若已配置 Network Dataset，再测试路径分析。
12. 导出 PDF。

## 数据与兼容性注意事项

- File GDB 当前只枚举根目录中的要素类，不遍历 Feature Dataset。
- MDB 依赖 Personal Geodatabase 支持及本机相关组件。
- 编辑功能要求数据源可写。
- 距离分析必须使用合适的投影坐标系。
- Network Analyst 路径图层必须提前配置，单独加载普通 Roads 图层不够。
- MXD 和数据应尽量使用相对路径或放在稳定目录。
- 不要把工程改成 x64；ArcGIS Engine 10.2 课程环境通常按 x86 配置。
- 不要把 ArcObjects DLL 从另一版本直接复制进工程。

## 常见问题

### 登录后地图空白

检查 `Resources/Futian.mxd` 是否被复制到输出目录，以及 MXD 中的数据源是否断开。

### GDB 能选中但提示没有要素类

要素类可能位于 Feature Dataset 中。当前代码只查看根目录，需要移动/复制一个测试要素类到根目录，或扩展枚举逻辑。

### 搜索按钮没有结果

先在 TOC 中选择正确图层，再检查该图层的 DisplayField、字段类型和实际属性值。

### 缓冲距离明显不对

检查图层坐标系。源码使用 500 个地图单位，不是强制 500 米。

### 属性编辑或新增点失败

检查文件是否只读、目录权限、数据源是否支持编辑，以及目标图层几何类型是否正确。

### 路径分析提示找不到 Stops 或 Routes

当前 MXD 中没有有效的 Network Analyst Route 图层，或网络数据源已经断开。应先在 ArcMap 中完成配置并验证。

### 程序提示无法获取 Network Analyst 许可

在 ArcGIS Administrator 中检查扩展许可，并确认程序启动时成功签出 Network Analyst。
