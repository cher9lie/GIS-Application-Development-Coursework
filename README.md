# GIS 应用开发课程作业（VS2010 / ArcGIS Engine 10.2）

本仓库用于整理和维护 GIS 应用开发课程作业，目标环境保持为：

- Microsoft Visual Studio 2010
- .NET Framework 4.0
- ArcGIS Engine / ArcObjects 10.2
- x86 目标平台

当前仓库刚建立，源码与文档仍在核对和整理中。原始文件已先行归档，详情见 [ORIGINAL_SNAPSHOT.md](ORIGINAL_SNAPSHOT.md)。

> 注意：这些项目依赖已经停止主流维护的 ArcGIS Engine 10.2，仅适合课程实验、旧系统复现和学习 ArcObjects，不建议直接用于新的生产项目。
